# صورت مسئله
1. یک سرویس ردیس داریم که می‌خواهیم فقط از طریق یک سرویس انجین ایکس روی پورت ۹۰۰۰ در دسترس باشد
1. محدودیت اتصال همزمان برایش لحاظ شود
1. تنظیم persistenct مناسب انجام شود
<br /><br />

# نحوه اجرا
کافی است دستور زیر را اجرا کنید:
```bash
docker compose up -d
```

### محدودیت اتصال همزمان
با استفاده از `worker_connections` در بلوک `events` [در فایل پیکربندی انجین ایکس](nginx/nginx-redis.conf) می‌توان تعداد اتصالات همزمان را محدود کرد. مقدار پیش‌فرض را ۱۰۲۴ در نظر گرفته‌ایم.
