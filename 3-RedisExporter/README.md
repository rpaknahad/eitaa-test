# صورت مسئله
1. افزودن یک redis exporter روی پورت ۹۱۰۰ به مسئله شماره ۲
1. امکان Basic Auth فراهم شود.
<br /><br />

# نحوه اجرا
1. اگر اولین بار هست که اجرا می‌کنید، لازم است یک نسخه از فایل [env.sample.](.env.sample) تهیه کنید و نام آن را `env.`  بگذارید و متغیرهای محیطی را به مقدار لازم تغییر بدهید.
2. سپس کافی است از پوشه اصلی اسکریپت [scripts/restart.sh](scripts/restart.sh) فراخوانی کنید
<br /><br />

# توضیحات فنی

## استفاده از مسئله شماره ۲
با توجه به این این مسئله در ادامه مسئله ۲ و در تکمیل آن مطرح شده، از قطعه کد زیر در فایل compose برای بارگذاری فایل آن پروژه و پیوست آن به پروژه فعلی استفاده شد:
```yaml
include:
- ../2-SafeRedis/compose.yaml
```

## پیکربندی
### احراز هویت ساده (Basic Auth)
برای تحقق این هدف، از دو متغیر محیطی زیر طبق [مستندات رسمی](https://github.com/oliver006/redis_exporter/blob/master/README.md#command-line-flags) استفاده شد:
- `REDIS_EXPORTER_BASIC_AUTH_USERNAME`
- `REDIS_EXPORTER_BASIC_AUTH_PASSWORD`

با تنظیم این دو متغیر، به‌طور خودکار مکانیسم احراز هویت ساده فعال می‌شود و هنگام اتصال به سرویس، لازم است نام کاربری و رمز عبور هم فرستاده شود.
